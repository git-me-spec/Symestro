# 🪄 Symestro

**Symestro** is an AI orchestration application that consults multiple AI models simultaneously via OpenRouter to deliver unified, synthesized answers.

🚀 **[Try Symestro Live Here](https://symestro.streamlit.app)**

---

## 🌟 Features
* **Multi-Model Orchestration**: Queries various AI models in parallel.
* **Unified Synthesis**: Blends key insights, resolves contradictions, and presents a complete response.
* **Simple Interface**: Powered by Streamlit for interactive and fast web access.

---

## 🛠️ Tech Stack
* **Frontend/Deployment**: Streamlit Cloud
* **AI API Gateway**: OpenRouter
* **Language**: Python
